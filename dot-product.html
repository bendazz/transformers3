The Dot Product

Multiplying vectors and understanding what the result means

1 What Is the Dot Product?

The dot product (also called the scalar product) takes two vectors and produces a single number. You calculate it by multiplying corresponding components and adding the results.

Formula: a · b = a1b1 + a2b2 + ... + anbn
2D example: [3, 2] · [1, 4] = (3)(1) + (2)(4) = 3 + 8 = 11
3D example: [1, 2, 3] · [4, 5, 6] = (1)(4) + (2)(5) + (3)(6) = 4 + 10 + 18 = 32

Notice that the result is a single number (a scalar), not a vector. Two vectors go in, one number comes out. This number tells us something important about how the two vectors relate to each other.

3 What Does the Dot Product Tell Us?

The dot product encodes information about the angle between two vectors. The sign of the result is especially meaningful:

Dot ProductAngle BetweenMeaning
Positive Less than 90° Vectors point in generally the same direction
Zero Exactly 90° Vectors are perpendicular (orthogonal)
Negative Greater than 90° Vectors point in generally opposite directions
Key idea: The dot product of perpendicular vectors is always zero. Try it in the calculator above: set A to [3, 0] and B to [0, 2]. The products are (3)(0) + (0)(2) = 0. This property is fundamental in linear algebra and comes up everywhere.

5 The Connection to Angles

The dot product is connected to the angle between two vectors by this formula:

a · b = ||a|| × ||b|| × cos(θ)

Where θ is the angle between the vectors. This means:

  • When θ = 0° (same direction), cos(θ) = 1, so the dot product equals the product of the magnitudes (its maximum)
  • When θ = 90° (perpendicular), cos(θ) = 0, so the dot product is 0
  • When θ = 180° (opposite), cos(θ) = −1, so the dot product is negative

Rearranging this formula gives us:

cos(θ) = a · b ||a|| × ||b||
Preview: This rearranged formula is exactly cosine similarity — the dot product divided by the product of the magnitudes. That's the subject of our next tutorial, and it's the core operation behind vector database search. The dot product is the essential building block.

6 Why This Matters for Databases

In a vector database, every similarity comparison between a query and a stored document involves computing a dot product. If your database has 1 million documents and each is a 1,536-dimensional vector, a single query requires:

OperationCount
Multiplications per dot product 1,536
Additions per dot product 1,535
Documents to compare 1,000,000
Total multiplications (brute force) ~1.5 billion

This is why vector databases use specialized index structures (like HNSW) to avoid computing dot products against every single document. The dot product is fast for one pair of vectors, but doing it a million times per query adds up.

1 Dot Product
Compute the dot product of [2, 5] and [3, -1].
Solution:
[2, 5] · [3, -1]
= (2)(3) + (5)(-1)
= 6 + (-5)
= 1
Interpretation:
Positive, so the vectors point in generally the same direction (angle < 90°).
2 Dot Product
Compute the dot product of [4, -3] and [3, 4].
Solution:
[4, -3] · [3, 4]
= (4)(3) + (-3)(4)
= 12 + (-12)
= 0
Interpretation:
Zero — these vectors are perpendicular (90° angle).
3 Dot Product
Compute the dot product of [1, -2, 3] and [4, 0, -1].
Solution:
[1, -2, 3] · [4, 0, -1]
= (1)(4) + (-2)(0) + (3)(-1)
= 4 + 0 + (-3)
= 1
4 Concept
Without calculating, what is the dot product of [5, 0] and [0, -3]? Why?
Answer:
0
Why:
[5, 0] points along the x-axis and [0, -3] points along the y-axis.
They are perpendicular, so their dot product must be 0.
Verify: (5)(0) + (0)(-3) = 0 + 0 = 0
5 Dot Product
Compute the dot product of [2, -1, 3, 4] and [-1, 2, 1, -2].
Solution:
[2, -1, 3, 4] · [-1, 2, 1, -2]
= (2)(-1) + (-1)(2) + (3)(1) + (4)(-2)
= -2 + (-2) + 3 + (-8)
= -9
Interpretation:
Negative, so the vectors point in generally opposite directions (angle > 90°).
6 Concept
What is the dot product of any vector with itself? Compute [3, 4] · [3, 4] and see if the result reminds you of something from the previous tutorial.
Solution:
[3, 4] · [3, 4]
= (3)(3) + (4)(4)
= 9 + 16
= 25
Insight:
25 = 5², and the magnitude of [3, 4] is 5.
The dot product of a vector with itself equals the square of its magnitude:
v · v = ||v||²
This is because √(x² + y²) squared is just x² + y².
7 Concept
Two documents are stored in a vector database as [1, 3, 2] and [2, -1, 1]. A user's query is embedded as [2, 2, 1]. Compute the dot product of the query with each document. Which document is more aligned with the query?
Query · Document A:
[2, 2, 1] · [1, 3, 2]
= (2)(1) + (2)(3) + (1)(2)
= 2 + 6 + 2 = 10
Query · Document B:
[2, 2, 1] · [2, -1, 1]
= (2)(2) + (2)(-1) + (1)(1)
= 4 + (-2) + 1 = 3
Conclusion:
Document A (dot product = 10) is more aligned with the query than Document B (dot product = 3).
Note: In a real vector database we'd use cosine similarity (which accounts for vector lengths) rather than the raw dot product. That's the next tutorial!
