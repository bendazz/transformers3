Introduction to Vectors

Understanding vectors visually before we use them in databases

1 What Is a Vector?

A vector is a quantity that has both a magnitude (length) and a direction. You can think of it as an arrow that points from one place to another.

We write a 2D vector as a pair of numbers. For example, the vector [3, 2] means "go 3 units in the x direction and 2 units in the y direction."

A 2D vector: v = [x, y]
Example: v = [3, 2]
A 3D vector: v = [x, y, z]
An n-dimensional vector: v = [v1, v2, ..., vn]

Each number in the vector is called a component. A 2D vector has 2 components, a 3D vector has 3, and so on. In vector databases, vectors often have hundreds or thousands of components — but the principles are the same.

2 Drawing a Vector

We draw a vector as an arrow from the origin (the center of the grid) to a point. The x component controls how far right or left the arrow goes. The y component controls how far up or down.

3 Magnitude (Length of a Vector)

The magnitude of a vector is its length. For a 2D vector [x, y], we calculate it using the Pythagorean theorem:

||v|| = √(x² + y²)

This works because the vector, its x component, and its y component form a right triangle. The magnitude is the hypotenuse.

Adjust the vector below. The dashed lines show the right triangle formed by the components, and the magnitude is computed live.

x² + y² = 9 + 16 = 25
√(x² + y²) = √25 = 5
Key idea: Two vectors can point in the same direction but have different magnitudes. For example, [1, 1] and [3, 3] point the same way, but [3, 3] is three times longer. This distinction between direction and magnitude is fundamental to understanding cosine similarity later.

4 Comparing Two Vectors

When we have two vectors, we can compare them by looking at the angle between them. Vectors that point in similar directions have a small angle between them. Vectors that point in very different directions have a large angle.

Vector A Vector B
Vector A: [4, 3]
Vector B: [1, 4]
Angle between: 45.0°
Try it: Make both vectors point in the same direction (e.g., A = [3, 2] and B = [3, 2]). The angle becomes 0°. Now make them point in opposite directions (e.g., A = [3, 2] and B = [-3, -2]). The angle becomes 180°. Try making them perpendicular (A = [3, 0] and B = [0, 3]) — the angle is 90°.

5 Vector Addition

Vectors can be added together by adding their corresponding components:

[ax, ay] + [bx, by] = [ax + bx, ay + by]

Visually, you can think of this as placing the second vector at the tip of the first. The result (shown in gold) goes from the origin to where you end up.

Vector A Vector B A + B
[3, 1] + [1, 3] = [4, 4]

6 Beyond 2D

Everything we've seen works in any number of dimensions. We can only draw vectors in 2D or 3D, but the math generalizes perfectly:

Operation2Dn-dimensional
Vector [x, y] [v1, v2, ..., vn]
Magnitude √(x² + y²) √(v1² + v2² + ... + vn²)
Addition [ax+bx, ay+by] [a1+b1, a2+b2, ..., an+bn]

In a vector database, each document is represented as a vector with hundreds or thousands of dimensions. We can't visualize a 1,536-dimensional vector, but we can still compute its magnitude, add it to other vectors, and — most importantly — measure how similar two vectors are.

Coming up next: In the next tutorial, we'll learn about cosine similarity — a way to measure how similar two vectors are by looking at the angle between them, regardless of their length. This is the core operation behind vector database search.

1 Magnitude
Find the magnitude of the vector [3, 4].
Solution:
||v|| = √(3² + 4²)
= √(9 + 16)
= √25
= 5
2 Addition
Add the vectors [2, 5] and [-1, 3].
Solution:
[2, 5] + [-1, 3]
= [2 + (-1), 5 + 3]
= [1, 8]
3 Magnitude
Find the magnitude of the vector [1, 2, 2].
Solution:
||v|| = √(1² + 2² + 2²)
= √(1 + 4 + 4)
= √9
= 3
4 Addition
Add the vectors [4, -2, 1] and [-3, 5, 2].
Solution:
[4, -2, 1] + [-3, 5, 2]
= [4 + (-3), -2 + 5, 1 + 2]
= [1, 3, 3]
5 Magnitude
Find the magnitude of the vector [5, -12].
Solution:
||v|| = √(5² + (-12)²)
= √(25 + 144)
= √169
= 13
6 Addition
Add the vectors [3, -1] and [-3, 1]. What do you notice about the result?
Solution:
[3, -1] + [-3, 1]
= [3 + (-3), -1 + 1]
= [0, 0]
Insight:
The result is the zero vector. This happens because [−3, 1] is the exact opposite of [3, −1]. Adding a vector to its opposite always gives [0, 0].
7 Magnitude
Find the magnitude of the vector [2, -3, 6, 1]. (4 dimensions!)
Solution:
||v|| = √(2² + (-3)² + 6² + 1²)
= √(4 + 9 + 36 + 1)
= √50
= 5√2 ≈ 7.0711
8 Addition
Add the vectors [1, 0, -2, 4] and [3, -1, 2, -4], then find the magnitude of the result.
Step 1: Add the vectors
[1, 0, -2, 4] + [3, -1, 2, -4]
= [1+3, 0+(-1), -2+2, 4+(-4)]
= [4, -1, 0, 0]
Step 2: Find the magnitude
||v|| = √(4² + (-1)² + 0² + 0²)
= √(16 + 1 + 0 + 0)
= √17
≈ 4.1231
